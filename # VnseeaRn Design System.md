English description: This document defines the VnseeaRn UI system for a compact, mobile-first app using brand blue, light neutral surfaces, subtle borders, and Vietnamese-friendly typography.

## Brand

Primary brand color: `#0000FF`

Use brand blue for primary actions, active tabs, selected states, key links, important icons, and confirmation accents. Avoid making the whole app blue.

## Color Tokens

Primary: `50 #eef0ff`, `100 #dfe4ff`, `200 #c5caff`, `300 #a1a4ff`, `400 #7b73ff`, `500 #0000ff`, `600 #0000e6`, `700 #0000cc`, `800 #0000a3`, `900 #000080`

Neutral: `50 #f8fafc`, `100 #f1f5f9`, `200 #e2e8f0`, `300 #cbd5e1`, `400 #94a3b8`, `500 #64748b`, `600 #475569`, `700 #334155`, `800 #1e293b`, `900 #0f172a`

Accent: `50 #fff7eb`, `100 #ffedd5`, `500 #f59e0b`, `600 #d97706`, `700 #b45309`

Status: `success #0ea5e9`, `warning #f59e0b`, `error #ef4444`, `info #3b82f6`

Background: `#f1f4fb`

Card surface: `#ffffff`

Text: Primary `#000000`, Secondary `#64748b`, Tertiary `#94a3b8`, Inverse `#ffffff`, Link `#0000e6`

Borders: Light `rgba(0, 0, 255, 0.08)`, Default `rgba(0, 0, 255, 0.12)`, Strong `rgba(0, 0, 255, 0.20)`

## Typography

Fonts: Inter, Be Vietnam Pro, system sans-serif

Scale: Display 28px extra bold, Heading 20px bold, Title 15px semibold, Body 14px, Caption 12px, Label 11px uppercase, Micro 10px.

Use Display for logo, hero values, money amounts, or major empty states. Use Heading for section headers, Title for cards and rows, Body for readable content, Caption for metadata, Label for badges.

## Spacing

Use a 4px rhythm: 4, 8, 12, 16, 20, 24, 32, 40, 48.

Common layout spacing: horizontal 16px to 20px, card padding 16px to 24px, row gap 10px to 14px, section gap 20px to 32px, button vertical padding 8px to 14px.

Keep mobile layouts dense but readable.

## Radius And Shadows

Radius: Small 8px, Medium 14px, Large 18px, XL 24px, Full 9999px.

Cards usually use 18px to 24px radius. Buttons and pills use full radius. Small controls can use 8px to 14px.

Shadows: Small `0 2px 8px rgba(0, 0, 255, 0.04)`, Medium `0 4px 20px rgba(0, 0, 255, 0.06)`, Large `0 8px 32px rgba(0, 0, 255, 0.09)`, Brand `0 4px 14px rgba(0, 0, 255, 0.28)`.

## Core Surfaces

Base screen: light blue-gray background, full height, safe-area aware.

Card: semi-transparent white, 1px soft border, blur, soft shadow, 24px radius, content-first layout.

Muted surface: light neutral background for filters, chips, panels, and inputs.

Brand surface: brand blue with white text for primary actions, selected states, or hero moments.

## Buttons

Primary: brand blue with slight transparency, blur, white text, full radius, medium/semibold, strong clean shadow.

Secondary: transparent or white, brand blue text, 2px blue border, full radius.

Ghost: transparent, inset shadow, secondary text, no border.

Icon button: at least 40px touch target, simple icon, high contrast, subtle background only when needed.

## Icons

Use clean line icons. Prefer Lucide-style icons for search, settings, back, close, notification, wallet, chat, send, plus, edit, filter, calendar, bookmark, heart, and share.

Use brand icon styles only for brand-specific actions such as Facebook or Google.

Sizes: XS 14px, SM 16px, MD 20px, LG 24px, XL 32px.

## Avatars

Avatar sizes: Small 32px, Medium 40px, Large 48px, XL 64px.

Use circular avatars. If no image is available, use initials on a brand or muted background.

## Bottom Navigation

Use a simple bottom tab bar when app-level navigation is needed:

- Feed
- Explore
- Reel
- Notifications
- Setting

Active tab: brand blue. Inactive tabs: neutral gray. Keep labels short.

## Consistency Rules

Do: use brand blue for primary actions, use the light app background, use white cards for grouped content, keep hierarchy compact, use Vietnamese text, create screen states, and respect mobile safe areas.

Do not: create a marketing landing page, use heavy gradients, use dark mode unless requested, make every section a floating card, use random colors, invent new font scales, use oversized desktop typography, or put business architecture into the design output.
